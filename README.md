# Hotel Aurocode

Hotel website built as a client demo by [Aurocode](https://github.com/Kushalsharma0702/Aurocode), my web studio.

## Stack

- TanStack Start with React and TypeScript
- Vite build tooling
- Radix UI components with a shared `components/` library
- Cloudflare Workers deployment configuration (`wrangler.jsonc`)

## Project layout

- `src/routes/`: file-based pages and routing
- `src/components/`: reusable UI components
- `src/hooks/`, `src/lib/`: hooks and utilities

## Run locally

```bash
npm install
npm run dev
```

## Status

Client demo / design prototype.
